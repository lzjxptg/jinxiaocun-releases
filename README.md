## 二、系统要求

- **Windows 10 / 11（64 位）**；不支持 Win7 与 32 位系统
- 无需安装 Python、数据库、Node 等任何环境；**可离线使用**
- 建议 4 GB 内存以上；磁盘约 500 MB（含数据）

## 三、安装与首次启动（绿色版）

1. 把 zip 解压到**有写权限**的目录，例如 `D:\进销存`
   （放 `C:\Program Files` 也能运行，但数据会改存到 `%LOCALAPPDATA%\进销存`，启动窗口会提示）
2. 双击 `JinXiaoCun.exe`，会弹出一个黑色小窗口显示"数据目录 / 访问地址"
3. 约 2~3 秒后**自动打开浏览器**进入登录页
4. 首次登录账号：**admin / admin123** → **请立刻改密码**（右上角「用户管理」）
5. **关闭那个黑窗口 = 退出程序**（浏览器页面随之失效）

> 首次运行时 Windows 可能弹"已保护你的电脑"（SmartScreen）：点「更多信息」→「仍要运行」即可。
> 安装包未做代码签名，这是正常提示。

## 四、数据放在哪、怎么备份

- 数据就在**程序目录下的 `data\db.sqlite3`** 一个文件里
- **备份 = 复制这一个文件**（建议每周一次，放到 U 盘或网盘）
- **换电脑 = 把整个程序文件夹拷过去**（或只把 `data\` 拷过去）
- 本软件**不联网、不上传任何数据**，数据完全在你自己的电脑上

## 五、注意事项（重要）

1. **不要两台电脑同时打开同一份数据库文件**（SQLite 单文件锁，容易互相覆盖）。
   多人同时用，请让数据放在**同一台机器**上，其他人通过局域网访问。
2. 程序运行中**不要直接删除或移动 `data\` 目录**。
3. 关机/重启前正常关闭程序（关掉那个黑窗口即可）。
4. 别把程序目录放在 U 盘里长期使用（速度慢、拔盘即断，且易丢数据）。
5. 忘了密码可以用管理员账号在「用户管理」里重置；**admin 密码务必保存好**。
